# PixiLab 🎨👾

[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com)

**PixiLab** is a powerful, lightweight, and intuitive Pixel Art & Frame-by-Frame Animation editor designed specifically for Android. Built with a focus on mobile workflow, it gives game developers and pixel artists the freedom to create sprites, tilesets, and animations anywhere, anytime.

## ✨ Features

### 🛠️ Advanced Pixel Art Tools
* **Essential Toolset:** Pencil, Eraser, Bucket Fill, Eyedropper, Selection, and Move tools.
* **Mirror Draw:** Symmetrical drawing modes (Horizontal & Vertical) for faster character and tile design.
* **Palette Management:** Create, customize, clear, or swap color palettes effortlessly.

### 🎬 Frame-by-Frame Animation
* **Clip Organization:** Separate your animations into clean, manageable clips (e.g., *Idle*, *Walk*, *Attack*).
* **Onion Skinning:** Toggle ghost frames to preview previous and next frames for buttery-smooth animations.
* **Timeline Controls:** Fast playback, frame duplication, precise frame-duration settings, and instant resizing.

### 📦 Pro Export Options
* **Multiple Formats:** Save your work as crisp **PNG**, **JPG**, **GIF**, or optimized **Sprite Sheets**.
* **Pixel-Perfect Upscaling:** Export from **x1 up to x16** scale to ensure your retro art stays pixel-perfect on high-res screens.
* **Batch Export:** Pack all your custom clips into a single **ZIP archive** in one click.
